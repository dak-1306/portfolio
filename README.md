# Personal Portfolio

A modern and responsive portfolio website built to showcase my projects, technical skills, and professional background as a Frontend Developer.

## Live Demo

[Portfolio Website](https://portfolio-chi-six-dis71bhv3s.vercel.app/)

## Features

- Responsive design for desktop, tablet, and mobile devices
- Interactive user interface with smooth animations
- Project showcase with detailed project pages
- Skills and technology overview
- Contact section with social links
- Modern space-themed design

## Tech Stack

### Frontend

- React
- TypeScript
- React Router
- Tailwind CSS
- Framer Motion
- shadcn/ui

### Tools

- Vite
- Git & GitHub
- Figma

```bash
src/

```

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
